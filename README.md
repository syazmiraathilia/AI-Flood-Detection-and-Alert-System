# 🌊 Muar-AI-Flood-Detection-and-Alert-System (Live Data & Prototype)

## 📌 Project Overview
An automated public safety warning system designed to predict and alert authorities about potential flash floods. This project is a **cross-faculty collaboration** between Computational Data Analytics and the Faculty of Engineering Technology, utilizing live IoT sensor telemetry from machines deployed at Sungai Muar.

## 🚧 Project Status: Prototyping & Live Data Ingestion
*Currently, the team is ingesting real-time data from the engineering hardware at Sungai Muar and developing the user interface (UI/UX) prototype.*

## ⚙️ System Architecture
1. **Hardware (IoT):** Engineering faculty sensors at Sungai Muar collecting real-time environmental telemetry (water levels, flow rates).
2. **Data Ingestion Pipeline:** Extracting live data from the IoT infrastructure for processing.
3. **Predictive AI Model:** Developing machine learning models to trigger real-time alerts based on anomaly detection.
4. **User Interface (UI):** Designing an accessible web/app interface (via Figma) to display live river conditions and alerts to the public and authorities.
5. **Alert System:** Automated notifications via WhatsApp, Telegram, and Web interfaces.

## 🛠️ Tech Stack & Tools
* **Data Source:** Live IoT Telemetry (Sungai Muar)
* **Data Processing:** Python, SQL
* **UI/UX Prototyping:** Figma
* **Alert Integration:** Telegram Bot API / WhatsApp API

## 🎯 Key Objectives
* Create a resilient, automated early warning system to minimize flood damage.
* Integrate hardware sensor data with predictive analytics.
* Provide real-time, accessible alerts to the public.
